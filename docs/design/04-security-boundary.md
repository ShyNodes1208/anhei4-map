## 7 Security Redlines — Implementation Verification

| # | Redline | How Enforced | Verifiable |
|---|---------|--------------|------------|
| 1 | No reading game process/memory/files | App only accesses its own `%LocalAppData%` + WebView2 user data dir. No `OpenProcess`, `ReadProcessMemory`, or file paths pointing to game dirs. | Code review: grep for `OpenProcess`, `ReadProcessMemory`, game paths |
| 2 | No injection or hooking | No `SetWindowsHookEx`, no `CreateRemoteThread`, no DLL injection. Only `RegisterHotKey` (standard Win32 API). | Code review: grep for `SetWindowsHookEx`, `CreateRemoteThread` |
| 3 | No simulated game input | No `SendInput`, `keybd_event`, `mouse_event`. Hotkeys are consumed by app, never forwarded. | Code review: grep for `SendInput`, `keybd_event`, `mouse_event` |
| 4 | No auto-navigation / player location | App has no concept of player position. No coordinate extraction from game or website. | Feature audit: no such code path exists |
| 5 | No unlisted API calls to website | WebView2 navigates to `https://helltides.com/` exactly. No XHR/fetch interception. No scraping of site data. | Navigation whitelist audit |
| 6 | No scraping or redistribution of map assets | No file download. No image extraction from WebView2. `IsPasswordAutosaveEnabled = false`. | Downloads blocked at WebView2 level |
| 7 | No script injection to hide ads or bypass restrictions | `ExecuteScriptAsync` is NOT used. `AddScriptToExecuteOnDocumentCreatedAsync` is NOT called. | Code review: grep for script injection APIs |

## Attack Surface Assessment

| Surface | Risk | Mitigation |
|---------|------|------------|
| WebView2 renders attacker-controlled content | Low | Navigation whitelist; only helltides.com allowed |
| JSON settings file tampering | Low | Malformed JSON → defaults + backup. No code execution from settings. |
| Hotkey registration conflict | Low | Registration failure → log + continue; no escalation |
| Mutex name squatting | Low | Named mutex prevents second instance; name is predictable (`Global\Anhei4Map_SingleInstance`) but low-value target |
| Log file injection (log forging) | Low | Log messages are app-generated; no user input echoed |
| Process termination (kill) | None | Local only; worst case: .tmp file from interrupted write cleaned on next start |

## Rollback Plan

If the shipped version has a critical defect:
1. User downloads previous release .zip from GitHub Releases.
2. Replaces .exe on disk.
3. `settings.json` is forward-compatible (extra fields ignored), so no data migration needed.
4. WebView2 user data directory is independent of app version.

No database. No migrations. No cloud service. Rollback = replace one file.
