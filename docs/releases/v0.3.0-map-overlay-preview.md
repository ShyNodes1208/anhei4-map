# v0.3.0 Map Overlay Preview

## Version Type
Preview snapshot

## Included
- Independent offscreen RendererWindow (1280x720)
- WebView2 loading helltides.com with security whitelist
- DOM map-region detection (multi-selector, largest candidate)
- Map visual readiness detection (img tiles / canvas / CSS background)
- CapturePreviewAsync PNG capture
- Full DOM map crop (no secondary square crop)
- Proportional OverlayWindow sizing (max 400x250)
- Default position Left=20, Top=20
- Default opacity 0.7
- Topmost transparent overlay
- Initial warm-up (3000ms) and finite capture retries (10 x 1000ms)

## Current Behavior
- HellTides map loads in background WebView2
- Map DOM region is captured
- Top-left semi-transparent overlay displays the map
- Original aspect ratio preserved
- Maximum size 400x250

## Known Limitations
- Map vertical viewport is still short (approx 3.17:1 ratio), cannot show all marked areas
- 3-second periodic refresh not implemented
- Mouse passthrough (WS_EX_TRANSPARENT) not implemented
- Global hotkeys not implemented
- Window dragging not implemented
- Settings UI not implemented
- Game character position sync not implemented
- Game memory/process access not implemented (redline)
