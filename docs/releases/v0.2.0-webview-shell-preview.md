# v0.2.0 WebView Shell Preview

## Version Type
Preview snapshot

## Included
- WPF borderless topmost window
- WebView2 Runtime detection
- Single-instance Mutex (Global\Anhei4Map_SingleInstance)
- HellTides full-page loading (https://helltides.com/)
- Safe navigation whitelist (DomainPolicy)
- Popup blocking (NewWindowRequested → Handled)
- Download blocking (DownloadStarting → Cancel)
- Window bounds restore (JsonSettingsStore + WindowBoundsNormalizer)
- Win32 P/Invoke adapter (Win32Interop)
- WindowStateMachine (3 states, 2 triggers)
- HotkeyDispatcher (8 commands mapping)
- FileLogger with 10MB rotation
- RetryPolicy (exponential backoff)
- Settings corruption recovery
